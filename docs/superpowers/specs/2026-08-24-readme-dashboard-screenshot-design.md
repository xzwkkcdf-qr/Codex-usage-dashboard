# README 仪表盘截图设计

## 目标

将 README 标题下方的产品图标替换为真实的产品界面截图，让访问者在首屏直接理解 Codex Usage Ledger 的用途和界面形态。

## 方案比较

1. 完整桌面仪表盘：信息最完整，能同时展示概览、图表和模型明细，最适合作为 README 主图。
2. 首屏局部裁切：文字和数据更大，但无法体现页面整体结构。
3. 计费明细弹窗：适合补充功能说明，不适合作为产品主图。

采用方案 1。

## 截图规范

- 使用中文界面和 1440px 宽桌面视口。
- 使用项目测试数据，不读取或展示用户本机的真实会话与用量。
- 截图等待页面完成加载，确保图表、指标和表格均为稳定状态。
- 截图保存到 `assets`，使用清晰、可辨识用途的文件名。
- README 标题下仅展示仪表盘截图，图标仍保留为程序品牌资产，但不再作为 README 主视觉。

## 验证

- 确认图片文件可正常打开且尺寸适合 GitHub README。
- 确认截图中没有加载态、错误态、滚动条遮挡或私人数据。
- 确认 README 的相对路径在仓库内有效。
- 运行现有 README / 发布契约测试，确保文档修改不破坏发布要求。
