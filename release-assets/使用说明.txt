Codex Usage Ledger（Codex 用量账簿）v1.0.0
================================================

快速开始

1. 将下载的 ZIP 完整解压到一个普通文件夹。
2. 双击 CodexUsageLedger.exe，不会弹出 CMD 窗口。
3. 本地服务就绪后程序会自动打开默认浏览器，并进入：
   http://127.0.0.1:5188
4. 需要停止程序时，在任务管理器中结束 CodexUsageLedger.exe。

重要提示

- 请勿只把 EXE 单独拖出文件夹，运行时需要同目录中的其他文件。
- 程序仅读取当前 Windows 用户目录中的本机 Codex 日志，不上传原始会话。
- 只有系统没有可用的默认浏览器时才会出现提示；正常情况下无需手动输入地址。
- 若 5188 端口已由同一程序占用，新启动的程序会打开现有页面后退出。
- 若 5188 端口被其他程序占用，程序会给出提示，不会结束那个程序。
- 如不希望自动打开浏览器，可在命令行运行：CodexUsageLedger.exe --no-browser

安全校验

请优先从项目的 GitHub Releases 页面下载，并使用同版本的 .sha256 文件核对 ZIP 的 SHA-256。Windows 可能因程序没有商业代码签名而显示来源提醒。
